Use the publishable key (or legacy anon key), never a secret/service-role key in browser code.
  1. Open Supabase → Project Settings → API Keys.
  2. Copy Project URL and publishable key.
  3. In index.html, replace YOUR_SUPABASE_PROJECT_URL and YOUR_SUPABASE_PUBLISHABLE_KEY.
  4. Commit the changed file to GitHub Pages and refresh.
